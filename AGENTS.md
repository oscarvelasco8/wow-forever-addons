# Continuidad del proyecto

Antes de trabajar, leer `docs/MEMORIA.md`, `docs/REGISTRO.md` y `docs/ALCANCE.md`.

- Mantener `docs/MEMORIA.md` con el estado actual, decisiones vigentes, comprobaciones y siguiente paso.
- Añadir a `docs/REGISTRO.md` los cambios relevantes, comandos de validación, resultados y limitaciones de cada sesión.
- No registrar secretos, tokens ni valores privados de entorno.
- Trabajar por fases y comprobar cada fase antes de avanzar.
- Rumbo y todas sus funciones son gratuitos. Las aportaciones son voluntarias y no conceden acceso ni ventajas.
- La plataforma se llama provisionalmente «WoW Forever Addons» y reúne todos los addons que se creen. Rumbo es un producto del catálogo, nunca la marca global.
- No mezclar el addon Lua con el código de la web. El repositorio de referencia es `oscarvelasco8/addon-rumbo`.
- Comunicar en español. No publicar ni afirmar que algo está desplegado si solo se ha comprobado localmente.
- Antes de entregar cambios de interfaz, comprobar visualmente el resultado en la web abierta. Si no se puede acceder a la sesión o al navegador, indicarlo y no dar la revisión visual por completada basándose solo en build o HTTP.
- El usuario está fuera de casa. Al terminar cada tarea, entregar capturas en la respuesta, incluida la revisión editorial. Conservar capturas anteriores, usar nombres por fase y actualizar memoria. Distinguir claramente las vistas previas con datos de ejemplo de las pruebas reales con sesión administrativa.
